vs 方案 A 关键差异: • 卡片顶部不再渲染 drag-handle 元素;Card.tsx 整体 cursor 改 grab。 • useSortable listeners 绑到 article 整个根(不再绑手柄);move 5px 阈值同 A。 • 点击 article → 仍触发 onClick(cardId) 进详情,移动 5px 内识别为点击 ≥ 5px 识别为拖拽。
方案 B · 视觉规则 · Trello 整张可拖
• cursor:cursor: grab(hover 时),cursor: grabbing(drag 时);无其他视觉装饰。
• 触发区域:整张卡片任意位置 → 拖拽;无专属手柄。
• 移动阈值:PointerSensor { activationConstraint: { distance: 5 } }(@dnd-kit 默认);5px 内 = 点击进详情。
• 冲突 UI:复用 StatusConstraintModal(零改动),拖拽中无预提示(D6 锁定)。
• 关键风险:移动 5px 阈值 + 整张卡都接受 listeners → 长按移动容易误触;点击进详情 与 拖拽起始 同一区域,鼠标静止 vs 微移需用户感知。
