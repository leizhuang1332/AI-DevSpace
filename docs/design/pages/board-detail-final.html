③ toggle state machine

右栏两态切换,默认=属性,展开=transcript。toggle 按钮在右栏顶部(图 2 中"在对话中打开" 即默认态的按钮,展开态显示"✕ 收起")
// 默认态(用户进入详情页)
state = 'property'
right_column = [💬 在对话中打开] + 属性表 + 关系 + 创建时间
ai_button = <button onClick={toggle}>在对话中打开</button>
// 触发 toggle
function toggle() {
state = state === 'property' ? 'transcript' : 'property'
// 不持久化(同 ADR-0022 D4.4 决策,默认回到 property)
localStorage.removeItem('board-card-side-state')
}
// transcript 态
state = 'transcript'
right_column = [head:标题 + 物理独立 badge + ✕] + 消息流 + 输入框
close_button = <button onClick={toggle}>✕</button> // 触发回到 property
// transcript 数据来源
transcript_path = ~/.aidevspace/requirements/<id>/board/tasks/<cardId>/transcript.yaml
transcript.scope = 仅描述 / 不发 Run(ADR-0028 D2 守门)
initial_context = parent_analyzing.transcript 派生 snapshot(K=10 条,K 由 impl 定)

默认态优点

  • 无 AI 推送即打扰(克制，在场)
  • 属性常驻,改字段 0 步操作
  • UI 比例稳定不抖动

展开态优点

  • AI 对话全屏,看清楚历史
  • 消息 + 输入一体化
  • 切回属性 1 步
