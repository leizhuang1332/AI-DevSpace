N 计数可见 无 有（按钮上） 有（把手角标） 有（抽屉标题）
运行中 Run dot 可见 无（走 Inline 提示栏） 无（折叠态；展开后有） 无（折叠态；展开后有） 实时
切换 Run 所需点击 3 步（⌘K → 搜 → ↵） 2 步（点按钮 → 点 Run） 2 步（点把手 → 点 Run） 1 步（点 Run）
窄视口 max-h-[200px] 复用 需重设 直接复用 需重设 当前
实现复杂度 低（删节点 + Cmd+K 入口） 中（折叠状态 + 按钮态样式） 中（hover/click 滑出动效） 最低
对 ADR-0021 决策 36 的改动 颠覆 增量（折叠态新增） 中等（抽屉位置换形态） 无
符合决策 24"克制在场" 过于隐身 完美 完美 过于常驻
误触风险 无 低（显式点击按钮） 高（悬停就展开） 无

📌 推荐：选项 B（折叠为按钮）

理由（基于决策表前三行 + 决策 24"克制在场"）：

  1. 主区宽度吃最少：默认态按钮只占 ~32px 视觉重量，比 D 的 320px 抽屉省 91%，比 C 的窄把手虽然多 8px 但按钮可点击区域更友好。
  2. N 计数在场：按钮上始终显示「🗂️ 历史分析 4」，符合"克制在场"哲学；A 完全隐藏让用户忘了历史存在。
  3. 窄视口 max-h-[200px] 复用：现有窄视口的折叠条天然就是 B 形态（max-h 限高 + 默认折叠 + 点击展开），无需重设窄视口布局。
  4. 对 ADR-0021 决策 36 增量友好：展开后 = 现有抽屉（无需重写 AnalysisHistoryDrawer 组件），只需新增一个折叠状态壳。
