方案 E · 视觉规则 · 快捷键 + Move 弹窗
• 禁用:useSortable + useDroppable + DragOverlay 全部移除;Card 整体不再 draggable。
• 快捷键:⌘↑ 移到上一列 head; ⌘↓ 移到下一列 head; ⌘← 前一张; ⌘→ 后一张; M 打开 Move 弹窗; ⌘↵ 确认。
• Move 弹窗:列出 5 列,当前所在列灰色不可选;点击其它列 → 触发 useMoveCardToColumn。
• 焦点视觉:outline:2px var(--brand) + box-shadow:0 0 0 4px var(--brand-50)。
• a11y:100% 键盘可达;无 drag 视觉反馈,移动仅靠 toast 提示「已移到 ... 列」。
• 关键风险:完全脱离"拖拽"语义,违背用户原始诉求;移动反馈弱(只 toast,无 ghost)。
