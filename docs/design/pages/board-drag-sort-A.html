方案 A · 视觉规则 · ADR-0035 D4
• 手柄位置:左侧,⋮⋮ 6 点 sprite(grid-template-columns:repeat(2,3px)),默认 opacity:0,group-hover:opacity:1。
• 触发区域:仅手柄 cursor:grab,激活按住 cursor:grabbing。卡片其他区域仍是 cursor:pointer。
• 移动阈值:PointerSensor { activationConstraint: { distance: 5 } }(@dnd-kit 默认);5px 内 = 点击进详情。
• 源卡:拖拽中 opacity:0.35(让位给 DragOverlay)。
• 目标列:border-color: brand + background: brand-50 + inset 0 0 0 2px brand-100。
• 冲突 UI:复用 StatusConstraintModal(零改动),拖拽中无预提示(D6 锁定)。
• a11y:决策 29「键盘 90% 走 Cmd+K」+ 决策 30 三态错误分层;键盘可拖(@dnd-kit KeyboardSensor 默认支持)。
