任务看板 · 5 列 status 颜色三方案对比

配套 ADR-0027(board section 引入)。本页面对 board section 的 5 列(backlog / todo / in_progress / in_review / done)配色做三方案对比。各方案仅在 列头部色点 + 列名色 + 列背景 tint 三处覆盖,卡片、卡片槽、toolbar、StatusBar 共享。
决策记录:决策 22「需求状态色 = 分组共享色(4 色 + 灰)」基础上扩展出 TaskCard 的 5 态配色。
